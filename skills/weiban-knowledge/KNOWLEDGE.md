# 微伴（Lyvu）公开知识库

本文件只包含可向普通用户公开的产品信息。账号实时状态、套餐、到期时间和额度必须调用只读账号查询，不能依据本文猜测。管理员接口、密钥、内部地址和运维信息不属于公开知识。

## 产品介绍

微伴（Lyvu）是多用户微信陪伴型智能对话平台。每位用户拥有独立账号、角色设定、会话、长期记忆、插件配置和微信连接，用户之间的数据彼此隔离。

## 注册、绑定与邀请码

- 微伴账号拥有永久邀请码。
- QQ 微伴社区通过“绑定 + 8 位邀请码”关联当前 QQ 用户，绑定后可签到、玩游戏、参加排行和使用积分功能。
- `绑定 ABCD1234`、`绑定ABCD1234`、`绑定邀请码 ABCD1234` 都是有效格式。
- 一个邀请码不能同时绑定同一通道中的多个用户。需要换绑时联系管理员处理。
- 群聊命令通常需要先 @机器人；交互卡片按钮可以直接点击。

## QQ 微伴社区

公开命令包括：社区帮助、签到、我的积分、积分明细、会员信息、今日运势、猜数字、猜拳、积分排行、周榜、月榜、今日发言排行。

积分来自签到、游戏和群发言榜。积分变动有不可变流水。管理员可以冻结积分账号或人工调整积分，但普通用户和聊天 Agent 不能执行管理操作。

Token 加油包使用独立 Token 钱包，不会修改会员的 5 小时、每周或每月套餐额度。兑换比例以机器人卡片和后台当前配置为准。

## 会员与 Token

- 会员等级为 Free、Lite、Pro，实时等级与到期时间以账号查询结果为准。
- 平台额度分别按最近 5 小时、本周和本月统计。
- Token 独立钱包在会员额度不足时继续抵扣；钱包充值或积分兑换应使用幂等订单，避免重复到账。
- 自带模型 Key（BYOK）和失败调用是否计入额度，以微伴后台实时规则为准；机器人不得自行估算余额。

## 角色、会话与记忆

用户可以配置角色名字、关系、性格、说话方式、边界和补充设定。保存角色设定会形成新的会话版本，历史会话可以切换和管理。

微伴通过最近消息、会话摘要、长期记忆、对话分段和梦境记忆保持连续对话。用户可以在后台管理长期记忆、摘要和聊天记录。

## 微信连接

用户在微伴后台扫码连接微信，并开启监听。连接异常时优先检查登录状态和监听开关；机器人只能解释公开操作步骤，不能索要登录凭据、Cookie、Token 或管理员密钥。

## 图片、语音和插件

微伴支持图片理解、人物形象、自拍生图、主动图片、表情包、语音回复和视频语音回复。实际可用性同时受全局插件开关、会员门槛、用户授权和个人开关影响。

内置玩法包括主动关心、定时任务、记账、梦境、语音回复等。某项能力不可用时，应提示用户检查后台开关与会员条件，不要承诺未查询到的权限。

## 安全与隐私

- 普通用户只能查询自己主动提供并有权使用的账号信息。
- 不向用户展示后台密钥、内部用户 ID、数据库数据或其他用户资料。
- 绑定、积分、兑换等写操作由确定性的社区插件执行，不由聊天 Agent 自由调用。
- 修改套餐、额度、有效期、积分和绑定关系属于管理操作，必须经过受控后台或专用流程。
