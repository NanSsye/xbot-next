# 实施与回退

1. 复用现有下载/哈希/安全解压逻辑，从提交归档准备独立源码目录。上游只支持源码 editable 安装；不改写已有第三方源码。
2. 使用 Python 3.14 和 `uv.lock`；协调 YAML、Anthropic 和 Windows 日志依赖。安装脚本与 Docker 同用锁文件。
3. 保留 Agent 适配层和策略规则，接入新版会话续接接口；权限检查覆盖最终工具参数、内联和直接调用。按 Agent 实例设置窗口，以临时系统提示注入群聊人设，兼容新版辅助模型解析。保持前端与 API 契约。
4. 用本地模型桩和独立 SQLite 验证。回退须恢复旧运行环境及升级前的 Hermes 数据快照，不用旧版本打开升级后的库。

升级涉及构建、环境和运行适配，超过三文件预算，分阶段实施和验证。线上不在范围内。
