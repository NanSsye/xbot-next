# 实施方案

1. 复用 `ui/src/ui/ConfigCenter.tsx` 的现有配置快照、草稿、校验、密钥显示、确认保存和回调机制，新增按配置分区嵌入的能力。
2. 删除控制台设置的通道标签；从外部通道卡片打开原生对话框，通过 `adapters.<name>` 精确筛选配置分区，并保留独立草稿。
3. 在卡片上下文中保留运行状态和操作，配置保存后沿用 `handleConfigApplied` 刷新全局状态；不改 API 和后端配置服务。
4. 只补充前端样式和必要的 SDD/图谱/目录说明；不顺手处理范围外告警。

## 复用说明
- 对齐 SYNDEX 的卡片开关、运行状态与右侧抽屉：保留原生 dialog 的焦点管理，在窄屏使用全宽，通道表单省去全局搜索及重复标题。
- 复用 `ConfigCenter`：保存、字段类型处理、敏感字段保护、配置冲突处理和 `onApplied` 回调均保持单一实现。
- 复用 `Channels`：卡片状态、二维码和启停交互不迁移到新组件，避免重复业务逻辑。
