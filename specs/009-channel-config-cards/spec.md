# 通道配置卡片化

## 背景
原页面将启停、扫码放在接入通道卡片上，但修改凭据需要到控制台设置再次选择通道。

## 做什么
- 在每个接入通道卡片内提供“配置参数”入口。
- 打开当前通道对应的配置分区，只展示该通道的字段，并沿用现有配置读取、校验、保存、密钥保护和热生效逻辑。
- 保留通道卡片中的启停、刷新状态、微信登录等现有操作。
- 移除控制台设置的“通道参数”标签。
- 保留“设置”页中的系统配置和 Agent/模型配置。

## 不做什么
- 不新增后端接口、数据库字段或配置路径。
- 不改变通道启停和登录流程。
- 不修改生产环境、Docker、Hermes 或第三方目录。
- 不删除后端对通道配置的支持。

## 验收标准
- 通道页默认只显示运行状态卡片。
- 四种外部通道点击卡片后从右侧打开独立配置抽屉；Web 只有启停，不增加空表单。启停开关不触发编辑；适配器运行状态不代表已登录。
- 保存配置后仍调用既有 `/config` 更新接口，并刷新通道状态。
- 配置编辑器可关闭，且不会把其他通道字段带入当前面板。
- `npm run build` 通过；相关前端测试或静态检查实际运行并记录结果。
