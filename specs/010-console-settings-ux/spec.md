# 控制台设置改版：用户看到什么，点下去发生什么

状态：已在本地实现并使用模拟接口验收，未部署。关键假设：保留现有配置和权限；管理员能改高级项；没有运行证据时不宣称服务可用。

## 最终页面
保留工作台左侧导航。设置内只有「AI 对话」「控制台偏好」「高级管理」三组；桌面紧凑横向切换，手机单列。页头提供搜索，可搜中文、原英文名或环境变量。命中项显示所在分组，选择后定位到具体字段。通道配置只在接入通道卡片维护。

AI 对话默认显示一行状态和一个与状态匹配的主操作，下方用紧凑列表显示模型服务、默认对话模型、群聊可选模型、会话设置。不是每个字段各占一张卡片。控制台偏好收纳基础信息、外观与访问安全。高级管理按网络与服务、数据存储与队列、运行与扩展分组，包含现有插件、技能及 Hermes 参数；不删除旧能力。技术标识、配置来源、恢复来源统一按需展开；来源阻止编辑或需要重启时就近提示。

## 首次使用
1. 未配置时首页显示「还没有连接模型服务」和「连接模型服务」。点开右侧抽屉，背景保留原列表位置。
2. 填「服务地址」「访问密钥」；标签下只解释用途和所需来源。示例：服务地址＝「填写模型服务商提供的接口地址，不是官网登录网址。」密钥＝「在服务商后台创建，用来授权 Xbot 调用模型。」兼容协议放在更多选项，默认选项须与现有配置一致。
3. 点「保存连接并获取模型」。先校验，再沿用现有保存确认，保存成功才获取模型。若第二步失败明确写「连接信息已保存，模型列表未获取」，重试不重复保存。不支持列表的服务提供手动输入模型 ID 的路径，并按现有可选模型约束校验。
4. 选择默认模型。如对话或模型调用仍关闭，列出实际关闭项和启用的影响，由用户确认，不静默打开两个开关。完成后给「去试聊」，跳到现有对话页，不自动发消息、不在设置中重复做聊天窗口。
5. 用户发送消息、看到真实回复即完成；微信是否登录是另一件事。未收到回复时不显示成功；只有能关联当前配置的试聊结果才允许显示「已验证」，没有该证据只写「已配置」。

## 日常使用与例外
- 换模型：点默认模型行的「更换」→ 选择 → 保存，返回原列表。密钥不必重填，群聊单独指定的模型不随之改写。
- 管群聊：点「群聊可选模型」管理允许选择的范围；移除正在使用的模型前先说明已知影响，影响不明不承诺自动迁移。
- 抽屉固定标题与底部操作，中段滚动；桌面沿用右侧抽屉，手机全宽。关闭、返回与 Esc 行为一致。有未提交修改时给「继续编辑」「放弃修改」，无修改直接关闭并归还焦点。保存期间禁重复提交。
- 空状态直接引导下一步；读取失败显示重试而非空表单。密钥被拒绝提示检查密钥；无法连接提示核对地址或网络；原因未知不猜。失败保留当前编辑内容，密钥不写浏览器草稿或日志。
- 英文品牌和模型 ID 保留；枚举显示中文用途，例如 `openai_compatible` 显示「OpenAI 兼容接口」，Skills 显示「技能」。字段说明回答一个实际问题；不重复配置来源，不让用户依赖悬停了解必填项。

## 验收
固定枚举选项逐项展示中文名称及选项下方的用途说明，可在选择前比较；提交仍使用原始枚举值。
首次使用者在不进入高级管理、无需旁人解释术语的条件下取得第一条回复；已有配置的用户可直接更换默认模型；错误能原地纠正并重试。桌面、390px 手机、仅键盘三种路径都能完成保存和取消。旧字段均可定位；切换分类不丢未保存修改；模拟测试与真实服务验收分别记录。
