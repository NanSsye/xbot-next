# 008-syndex-console-design 技术方案（plan）：按 SYNDEX 工作台重整 Xbot 控制台

> 关联 spec：[spec.md](./spec.md) | 最后更新：2026-11-26

## 1. 技术方案概述
- **CRITICAL**：仅移植已验收的前端改动，沿用公共发布基线、原配置快照与写入协议。不触碰运行环境或部署配置。
- 以 SYNDEX 对话区的中性外壳和对话宽度为基准；保留 Xbot 功能与品牌，不引入依赖。
- 先调整共享主题、页头和对话，再重排设置；按稳定键归类，未知配置仍有入口，搜索能显示进阶项。

## 2. 前端改动点
| 文件/页面/组件 | 改动 | 图谱节点 ID |
|----------------|------|-------------|
| 外壳、共用页头、对话 | 中性主题、紧凑标题和聊天栏宽 | page.agent-workspace |
| 配置中心 | 模型优先、用途分类、进阶折叠、保存前按需检查 | component.agent-model-settings |
| 接入通道卡片 | 复用原卡片及图标容器，使用浅底、本地品牌 SVG 和现有浏览器图标；未知通道仍用通用图标 | page.channel-management |
| 浏览器标签 | 在 HTML 入口声明 favicon，复用现有吉祥物静态资源 | component.console-shell |

## 3. 后端改动点
| 文件/接口/服务 | 改动 | 图谱节点 ID |
|----------------|------|-------------|
| 配置 API | 沿用，无改动 | |

## 4. 接口与数据模型变化
无 API、数据模型或迁移变化。

## 5. 风险
| 风险 | 影响 | 应对 |
|------|------|------|
| 窄屏或深色下表单横溢 | 工作区可用性 | 浏览器核对窄屏、深色与长配置项 |
| 品牌资源在离线局域网无法加载 | 卡片识别 | 图标随构建发布，在明暗主题验证，无外部网络请求 |

## 6. 回滚方案
只撤销本次前端差异，不做数据回滚。

## 7. 知识图谱变更计划
更新前端工作台、设置和通道展示；后端不变。
